# hxwl-11 圆锥角膜随访台

圆锥角膜患者复诊录入、转专科判定与交联设备排程。

## 技术栈

React + Vite + TypeScript + CSS（无额外依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 功能

- 随访录入：患者、眼别、检查日期、角膜最薄点、Kmax、半年变化量、治疗阶段；同一患者同一天同眼只保留一条
- 自动判定：最薄点 < 400μm 或半年变化 > 25μm 时保留输入并转专科待确认，且不能占用交联设备
- 设备排程：交联设备同一时段只能排一人；确认锁定后排程不可取消
- 确认锁定：确认后的检查与排程锁定；复诊参数变化需新建带原因的版本，旧值保留在版本链中可查
- 左侧筛选（状态 / 眼别 / 治疗阶段 / 患者检索）与顶部指标随记录状态实时刷新
- localStorage 落盘：重开页面后记录、设备占用与版本链均在

## 目录结构

- `src/domain/types.ts` — 领域模型（记录、版本、设备占用）
- `src/domain/rules.ts` — 判定规则（转专科阈值、去重键、时段冲突）
- `src/data/store.ts` — 持久化与状态操作（localStorage）
- `src/App.tsx` — 页面（录入、筛选、指标、设备时段、版本链）
