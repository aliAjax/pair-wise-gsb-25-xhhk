# 圆锥角膜随访台 · 交联设备排程

纸质复诊记录难以判断能否继续排程。本应用将圆锥角膜复诊做成可落盘的随访工作台：
录入参数后自动判定是否转专科、确认后锁定检查与排程、复诊改参数保留带原因的版本链，
数据关闭重开后仍在。

## 功能

- **录入**：患者、眼别、检查日期、角膜最薄点（μm）、Kmax（D）、半年变化量（μm）、治疗阶段。
- **唯一约束**：同一患者 + 同一天 + 同眼只保留一条；待确认时再录入直接更新该条。
- **专科阈值**：最薄点 < 400μm 或半年变化 > 25μm 时，输入保留并置为「转专科待确认」，
  只能由专科医师确认；即使确认后也**不能占用交联设备**。
- **确认与锁定**：普通记录医师确认即锁定；锁定后参数变化必须填写原因并生成新版本（v2、v3…），
  旧值、确认人与确认时间在版本链弹窗中均可查。
- **设备排程**：一台交联设备，同一日期+时段只能排一人；仅「已确认且未触发阈值」的记录可选；
  排程创建即锁定，不提供取消/改期入口。
- **左侧筛选**：姓名/病历号、眼别、确认状态、治疗阶段、专科风险；顶部 5 个指标卡随状态实时刷新，
  点击可联动列表或跳转排程页。
- **落盘**：数据保存在浏览器 localStorage（单键、带数据版本号），重开页面记录、设备占用、
  版本链均保留；支持 JSON 导出 / 导入备份与一键清空。首次打开自带示例数据。

## 分层结构（数据 / 判定 / 存储 / 页面分开，无新增运行时依赖）

```
src/
  types.ts                 领域模型（记录、版本、排程、筛选、统计）
  domain/
    rules.ts               阈值判定、唯一键、录入/确认/排程/删除（纯函数）、统计与筛选
    storage.ts             localStorage 读写、迁移、导入校验、示例数据
  data/
    useStore.ts            React 状态与落盘之间的唯一桥梁
  components/
    MetricBar.tsx          顶部指标
    FilterSidebar.tsx      左侧筛选
    VisitForm.tsx          录入 / 复诊再录入（含原因版本）
    RecordTable.tsx        记录列表、确认/删除、状态徽标
    VersionModal.tsx       版本链查看
    ScheduleBoard.tsx      交联设备时段与占用台账
  App.tsx                  页签、联动、备份、操作员身份
scripts/test-domain.mts    判定层纯函数断言（26 项）
```

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5111
npm test           # 判定逻辑测试
npm run typecheck  # 严格类型检查
npm run build      # 生产构建
```

## 说明

- 纯前端、单机存储，不涉及任何外部服务；专科身份、操作员仅用于本地署名与确认权限演示，
  不构成真实电子病历的访问控制。
